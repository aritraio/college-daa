# Experiment 1: Recursion Basics — Q3. Factorial / Fibonacci Using Recursion

## Problem Statement
Write a recursive program to generate the Fibonacci series and the factorial of a number. The program reads `n` and prints the first `n` terms of the Fibonacci series (starting with 0, 1, 1, 2, …) and the factorial of `n`.

## Algorithm & Approach
- **Fibonacci:** `fib(0) = 0`, `fib(1) = 1`, and for `n ≥ 2`, `fib(n) = fib(n-1) + fib(n-2)`. The series is generated by calling `fib(i)` for every `i` from 0 to `n-1`.
- **Factorial:** `fact(0) = 1`, and for `n ≥ 1`, `fact(n) = n × fact(n-1)`.
- Both functions use the standard two-branch / single-branch recursive definitions with simple base cases; no loops appear inside the recursive functions themselves.

## Pseudocode
```
function fib(n):
    if n <= 1: return n
    return fib(n - 1) + fib(n - 2)

function fact(n):
    if n <= 1: return 1
    return n * fact(n - 1)

read n
for i = 0 to n - 1:
    print fib(i)
print "Factorial of n: fact(n)"
```

## Complexity Analysis
- **Time Complexity:**
  - Factorial: O(n) — one recursive call per value down to the base case.
  - Fibonacci (naive, per call): O(2ⁿ) — each call branches into two calls; generating `n` terms is O(n · 2ⁿ).
- **Space Complexity:** O(n) — the recursion stack depth for both functions.

## Sample Input & Output
```
Input:
6

Output:
Fibonacci series (6 terms): 0 1 1 2 3 5
Factorial of 6: 720
```
